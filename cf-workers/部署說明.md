## Step 1：執行 D1 Schema（建資料表）

1. 前往 https://dash.cloudflare.com/d4770362a33e464a2de08079e41c8f66/d1
2. 點「market-tracker-db」
3. 點上方「Console」分頁
4. 把 schema.sql 的全部內容貼入
5. 點「Execute」
6. 看到 Success 即完成

---

## Step 2：建立 Worker

1. 前往 https://dash.cloudflare.com/d4770362a33e464a2de08079e41c8f66/workers-and-pages
2. 點右上角「建立應用程式」
3. 點「建立 Worker」
4. 名稱填：market-tracker
5. 點「部署」（先部署預設 hello world）
6. 部署成功後點「編輯程式碼」
7. 清除全部預設程式碼，把 worker.js 全部內容貼上
8. 點右上角「部署」

---

## Step 3：綁定 D1 資料庫

1. 回到 Worker 頁面 → 點「設定」分頁
2. 找「繫結 (Bindings)」→「D1 資料庫」→「新增繫結」
3. 變數名稱填：DB
4. 資料庫選：market-tracker-db
5. 點「部署」儲存

---

## Step 4：設定 Cron（每週自動爬取）

1. 在 Worker 設定頁 → 「觸發器」分頁
2. Cron 觸發器 → 新增排程
3. 填：0 0 * * 1（每週一 00:00 UTC，台灣時間週一 08:00）
4. 儲存

---

## Step 5：填入前端 API 端點

1. 打開飛比特儀表板 → 品類競品分析
2. 點「⚙️ 設定」→「Cloudflare 後端設定」
3. 填入：https://market-tracker.esuse-adobe.workers.dev
4. 點「測試連線」→ 看到「✅ 連線成功」即完成

---

## 選填：YouTube API Key

1. 前往 https://console.cloud.google.com
2. 建立專案 → API & Services → 啟用 YouTube Data API v3
3. 建立 API Key
4. 在 Worker 設定 → 環境變數 → 新增：
   - 名稱：YOUTUBE_API_KEY
   - 值：（你的 API key）
